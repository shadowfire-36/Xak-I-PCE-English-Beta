XAK I — PC ENGINE CD ENGLISH BETA 2

This is an experimental public-playtest package. Xak I only; Xak II is not translated by this release. No game image or BIOS is included.

PATCHING TOOL
Delta Patcher (Windows/macOS/Linux), official releases:
https://github.com/marco-calautti/DeltaPatcher/releases
This applies .xdelta patches. PPF-O-Matic is not used. Download the tool separately; it is not bundled.

REQUIRED ORIGINAL
Unmodified Japanese Xak I & II whole-disc raw image, 2352 bytes per sector.
File length: 563,057,040 bytes
CRC32: 6BD28D3D
SHA-256: 3ba67343d89ad199e93acd4724ba044c1177b8b2b1a2ffb593c9e51ac06d3f56
The supplied source was named Xak_1_and_2_(NTSC-J)_[TJCD2032].iso. Its extension is .iso, but it contains RAW 2352-byte sectors. A filename alone does not establish compatibility.
A CHD, separate-track BIN set, 2048-byte-sector ISO or different dump is not the required input. Renaming one will not convert it.

INSTALLATION
1. Extract this ZIP to a folder.
2. Make a COPY of your matching original disc image. Name the copy Xak_I_Beta_2.iso. Keep your original unchanged.
3. Open Delta Patcher in Apply Patch mode. Select that COPY as Original file.
4. Select Xak_I_English_Beta_2.xdelta as XDelta patch, then apply it. Keep checksum validation enabled. Stop if the tool reports a mismatch; do not force the patch.
5. Confirm the patched image matches the expected checksums below.
6. Place Xak_I_Beta_2.cue beside Xak_I_Beta_2.iso. Open the CUE in your PC Engine CD emulator with your own compatible System Card BIOS. The CUE retains the disc's audio/data track layout.
7. Choose Xak I. Keep your existing saves backed up separately. Do not patch an already-patched image or apply both patch formats.

CHECKING SHA-256 ON WINDOWS
Right-click Verify SHA256.ps1 and choose Run with PowerShell, or use a checksum utility. The script asks you to select an image and identifies the exact original or patched beta by SHA-256. Full CRC32/SHA-256 values are also in CHECKSUMS.json.

UPDATING FROM BETA 1
Apply Beta 2 to a clean matching ORIGINAL, not the Beta 1 image. Power-cycle the emulator after opening the new CUE. Older emulator save states can restore old cached Japanese text; prefer your normal in-game save when possible. Keep every save backed up.

BETA 2 CHANGES
The two reported help choices now read WILL YOU HELP?; unrelated WHAT NOW? choices retain their original meaning. The repeated Fray path and mirrored copies are included. Latok's repeated name label is omitted in these tight question slots.
The loading blessing line is translated. Item and quest menu tables are translated in all 36 matching Game I copies, with short English names to fit the original menu width. Additional untouched equipment-name copies are translated.

SCOPE AND KNOWN LIMITS
1,169 exported Japanese/English source pairs: dialogue, shops, equipment labels and system text. This count is not proof of a complete natural playthrough.
A full natural playthrough, every choice branch and normal in-game saving are not verified.
Native SAVE stalled from an imported cave snapshot in both earlier and beta builds. Save-state creation/reload passed in private Mesen testing; back up saves and report save behavior.
Japanese cinematic audio and movie staff-credit graphics remain unchanged. No English voice dubbing.
Please report untranslated text, clipped text, wrong speakers, crashes, save problems or progression blockers. Include emulator/version, scene, screenshot, reproduction steps and an optional save state.
